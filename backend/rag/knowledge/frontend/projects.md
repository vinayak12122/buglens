# Project Management Interface

Projects act as the primary organizational unit within BugLens.

Users can create and manage multiple projects from the dashboard.

Each project maintains its own:

- API keys
- Issues
- Logs
- Monitoring data
- SDK integrations

The project interface allows users to:

- View project information
- Access issue dashboards
- Inspect logs
- Manage settings
- Generate public API keys

Project-specific views help isolate application data and provide a structured monitoring experience.
