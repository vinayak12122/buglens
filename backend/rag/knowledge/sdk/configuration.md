# Breadcrumbs

Breadcrumb tracking is not currently implemented within the BugLens SDK.

The current SDK focuses on:

- Error capture
- Event batching
- Event transport
- Project identification through API keys

Future versions of BugLens may introduce breadcrumb support to provide additional context leading up to an error event.

Examples of potential breadcrumb data include:

- User interactions
- Navigation activity
- Network requests
- Application state changes

At the current stage of development, breadcrumb collection is not available.
