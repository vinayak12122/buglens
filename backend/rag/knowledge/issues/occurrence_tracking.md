# Occurrence Tracking

## Overview

Occurrence tracking measures how many times an issue has appeared within a project.

Every time an event is matched to an existing issue, the issue occurrence count increases.

## Purpose

Occurrence tracking helps developers understand:

- Error frequency
- Error severity
- Impact on users
- Growth trends

Issues with high occurrence counts often indicate problems affecting a large number of users.

## Tracked Information

BugLens may maintain information such as:

- Total occurrences
- First occurrence timestamp
- Latest occurrence timestamp

This information helps developers determine whether an issue is new, recurring, or actively impacting applications.

## Dashboard Usage

Occurrence counts are displayed within issue views and dashboards.

Developers can use this information to prioritize investigations and allocate resources more effectively.
